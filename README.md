# PM2.5 Explorer

ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย (รายวิชา 1145100 Data Science Toolbox)

## วิธีติดตั้ง
ใช้ [uv](https://docs.astral.sh/uv/) (Python 3.14)

```bash
uv sync
```

รันโค้ดผ่าน `uv run` เช่น `uv run streamlit run app/<ไฟล์>.py`
สำหรับ notebook ให้เลือก kernel `.venv` ของโปรเจกต์
